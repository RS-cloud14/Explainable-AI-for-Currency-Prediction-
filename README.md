# COIL Project Group 11

## 📌 Overview
This repository contains the data analysis and findings for **COIL Project Group 11**, focusing on car ownership, purchasing behavior, excise duty awareness, and traffic congestion. The analysis is performed using **Python** in a Jupyter Notebook.

## 🎯 Objectives
- Examine factors influencing car ownership and purchase decisions.
- Analyze perceptions toward vehicle excise duty.
- Explore attitudes toward public transport, fuel price, carpooling, and congestion.
- Provide insights for potential policy implications.
